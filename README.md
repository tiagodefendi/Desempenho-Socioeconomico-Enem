# Desempenho Socioeconomico Enem

Trabalho desenvolvido para a disciplina de Tópicos em Engenharia de Software voltada para Ciência de Dados (Mestrado). O objetivo do projeto é realizar uma análise regional e socioeconômica sobre o desempenho dos candidatos no ENEM, identificando padrões e disparidades nos resultados.

---

# Dados

## Dataset Principal (Dados do Enem)

A base de dados principal deste estudo é constituída pelos microdados do Exame Nacional do Ensino Médio (Enem), disponibilizados pelo Governo Federal por meio da Lei de Acesso à Informação (LAI). Foram coletados os dados históricos compreendidos entre os anos de 1998 e 2024, limitando-se ao volume de informações públicas disponíveis na plataforma oficial até o período de realização desta análise. Site com os Microdados -> ([CLIQUE AQUI PARA ACESSAR OS DADOS](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem))
